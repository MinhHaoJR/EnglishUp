# Japanese and Chinese learning spaces

The sidebar learning-language picker is separate from the Vietnamese/English UI language. English retains its existing courses. Japanese and Mandarin Chinese (simplified script) each have a distinct home screen, a 2,000-entry vocabulary catalog and three original beginner lessons for reading, listening, speaking and writing. This is a starter collection, not a complete JLPT/HSK curriculum.

Content lives in `src/data/languages.json`, validated at module load with Zod. Each lesson needs a unique prefixed ID, target script, romaji/pinyin, bilingual meaning, original short passage, bilingual question/options and a valid answer index. Add original content only.

Attempts use the shared Dexie log with an explicit learningLanguage. Historical attempts without that field belong to English. Settings without a target language default to English on load/import. Backup version 1 remains compatible; it includes the new settings/attempt fields and writing submissions. No database index migration is needed because filtering is currently in memory.

Listening uses installed browser speech voices with ja-JP or zh-CN; availability and pronunciation depend on the device. Speaking explicitly records self-assessed completion, not measured pronunciation accuracy; no microphone or audio recording is used. Hardware was not verified. Writing compares a short phrase to one model after width/space/punctuation normalization and stores submitted text; alternative correct translations are not recognized. Unsubmitted answers are session-only and switching languages discards them. Learning progress is isolated; display settings and backup/reset apply to the whole app.

## Vocabulary catalogs — 2026-10-10

Each language has 2,000 distinct headwords and useful expressions across 20 daily-life topics. This is an editorial learning collection, not a corpus-ranked frequency list, an official JLPT/HSK syllabus or an exhaustive dictionary. Entries teach one selected sense with concise original Vietnamese and English glosses. Japanese entries include kana readings and romaji; Chinese entries use simplified characters and tone-marked Mandarin pinyin. Romaji and pinyin are learning aids; these entries have not been independently certified by a language educator. Contextual example sentences are not included in this catalog expansion.

Authoring sources are UTF-8 pipe-separated files `scripts/content/japanese-vocabulary.txt` and `scripts/content/chinese-vocabulary.txt`. Columns: `id|topic|text|reading|romanization|Vietnamese meaning|English meaning`. Keep IDs and headwords stable. Use the same concise English gloss for equivalent senses (for example, both 車 and 自動車 use `car`), and separate alternative meanings with semicolons, so practice can exclude equivalent answers. Topic keys and translated labels live in `src/data/languageVocabulary.ts`. Run `node scripts/build-language-vocabulary.mjs`, followed by `npx prettier --write src/data/language-vocabulary.json`, to regenerate the catalog. The generator validates both sources and checks counts, required fields, registered topics, language prefixes, unique IDs and unique normalized headwords before replacing the JSON. Startup additionally validates the catalog with Zod.

The library displays at most 24 cards per page. Search works across target script, kana, romaji/pinyin, Vietnamese and English; Latin accents and spaces are optional, while meaningful Japanese voiced marks remain distinct. Topics support direct links through `?topic=<key>`. Changing search or topic resets pagination. Speech uses the existing browser voices and never stores audio.

Practice selects up to ten words from the current topic/search results. Starting from a word card puts that word first. Four meaning options come from the same language, excluding matching glosses and overlapping listed translations in either interface language. This uses the authored glosses, not semantic AI grading. The answer is saved before Continue appears; a failed save keeps the answer for retry. Results use the shared attempts table with `learningLanguage` and the target headword as the label. Counts show distinct practiced words, not certified mastery. This practice does not alter English SRS schedules or daily new-card limits. Leaving early retains saved attempts; unanswered questions are session-only. Backup/reset/import includes both languages' results without a schema migration.

The refreshed interface uses a warm paper background, rose accents for Japanese and jade accents for Chinese. Topic chips, reading lines, clear cards, keyboard focus and responsive layouts support larger catalogs. Dark mode uses matching dark surfaces. The existing three starter lessons are retained; additional vocabulary does not create new reading/listening passages.
